## 项目管理

### 整体流程

1. **准备阶段**
   1. **库表设计** 
   2. 建立分支  
   3. 创建实体类，xml，mapper，service 等文件。
2. **业务逻辑开发阶段** 
   1. 封装所有接口入参为 dto
   2. 业务开发
   3. 封装出参为 vo 返回
3. **测试阶段**
   1. 使用 apifox 或 postman 进行接口测试
4. **提交代码阶段**
   1. 更新代码
   2. 推送代码
   3. 提 pr





### 关键集成逻辑

```mermaid
sequenceDiagram
		autonumber
		actor User as 用户
		participant Insert as 入库
		participant Role as 角色分配
		
		User->>Insert: 1. 带参数，创建项目
		Insert->>Insert: 2. 参数校验
		Insert->>Insert: 3. insert project
		Insert->>Insert: 4. insert contract
		Insert->>Insert: 5. insert stage
		Insert->>Role: 6. 分配角色
		
		Role->>Role: 7. insert role_user
		Role->>Role: 8. insert member
```





注意：一个项目可能多个阶段同时开始！

## 验工审批

### 整体流程

1. 准备阶段

- 确保项目本阶段已经完成

2. 核心阶段

- **项目经理**提交验工单
- 然后后面进行审核



### 关键集成逻辑

```mermaid
sequenceDiagram
		autonumber
		actor User as 项目经理
		participant Insert as 记录
		participant Approval as 审批
		
		User->>Insert: 1. 带参数，提交工单
		
		Insert->>Insert: 2. 参数校验
		Insert->>Insert: 3. insert inspection_form
		Insert->>Insert: 4. insert approval_records
		
		Insert->>Approval: 5. 审批人审批
		
		Approval->>Approval: 6. 审批人1审批，指定下一人，新增记录（更新状态）
		Approval->>Approval: 7. 审批人2审批，指定下一人，新增记录
		Approval->>Approval: 8. 审批人n审批，指定下一人，新增记录
		Approval->>Approval: 9. 最后一个审批人审批
		
		Approval->>Insert: 10. 修改工单表状态
		
		Insert->>User: 11. 通过审批
```
