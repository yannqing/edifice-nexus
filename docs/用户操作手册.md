# 然而信工程管理系统用户操作手册

版本：v1.0  
适用系统：Edifice 工程管理系统 + Gougu OA 集成系统  
适用对象：项目经理、项目成员、审批人、财务/绩效人员、系统管理员、普通员工

## 1. 手册说明

本手册用于指导用户完成系统中的日常操作，包括登录、项目管理、项目文件、验工审批、产值分配、回款、合同、归档、消息待办、OA 申请、权限与用户管理等。

系统当前由两个部分组成：

- Edifice 工程管理系统：负责工程项目、合同、验工、项目文件、产值分配、回款、统计报表、消息待办等业务。
- Gougu OA 系统：负责组织、人事、员工、岗位、角色权限、行政办公、财务审批等 OA 能力。

两个系统之间已做集成：

- 用户、部门、岗位、权限等基础数据以 OA 为主要维护入口。
- Edifice 使用 OA 同步过来的用户和权限。
- Edifice 可跳转进入 OA，OA 也可跳转回 Edifice。
- 权限在 OA 中配置，Edifice 根据同步后的权限控制侧边栏菜单和接口访问。

## 2. 登录与退出

### 2.1 登录 Edifice

1. 打开 Edifice 登录页。
2. 输入用户名、邮箱或 OA 员工账号。
3. 输入密码。
4. 点击“登录”。
5. 登录成功后进入“工作台”。

注意事项：

- Edifice 支持使用 OA 中维护的账号密码登录。
- 如果账号、密码或权限刚在 OA 中修改，可能需要重新登录。
- 如果登录后提示“暂无权限访问该功能”，说明当前账号未分配对应菜单权限，需联系管理员在 OA 中配置权限。

### 2.2 退出登录

1. 点击左下角用户头像区域旁的退出按钮。
2. 系统清除当前登录状态。
3. 页面跳转回登录页。

### 2.3 权限变更后的重新登录

当管理员在 OA 中修改了用户的角色、岗位或权限后，Edifice 会定期检查当前用户权限是否变化。

如果检测到权限变化，系统会提示：

> 您的相关信息已经修改，请您重新登陆。

此时按提示重新登录即可获取最新菜单权限。

## 3. 系统首页与导航

### 3.1 侧边栏菜单

Edifice 侧边栏按业务分组展示。当前主要分组如下：

| 分组 | 菜单 |
| --- | --- |
| 首页 | 工作台、消息中心、统一待办 |
| 日常工作 | 我的项目、验工审批、工时填报、OA 申请 |
| 项目管理 | 全部项目、项目生命周期、验工单管理、合同管理、项目归档、项目文件审批、投标管理 |
| 绩效 | 产值分配、回款记录 |
| 报表统计 | 统计报表、个人绩效、人员分配汇总 |
| 系统管理 | 用户管理、公告管理、操作审计、流程配置中心、业务规则配置 |

注意事项：

- 菜单是否显示取决于当前账号权限。
- 超级管理员可看到全部菜单。
- 普通用户默认通常应包含“工作台”“我的项目”“个人绩效”等基础菜单，具体以 OA 权限配置为准。

### 3.2 工作台

工作台用于快速查看当前登录用户相关的业务概况。

主要内容包括：

- 在研项目总数
- 产值总额
- 已发放产值
- 待审批验工单
- 待办事项
- 项目进度
- 公告信息
- OA 入口

常用操作：

1. 查看个人参与项目的统计数据。
2. 点击待办事项进入对应审批或处理页面。
3. 点击 OA 入口进入 OA 系统。
4. 查看公告，了解系统或公司通知。

## 4. 消息中心

消息中心用于查看系统内通知。

### 4.1 消息分类

消息中心支持以下分类：

- 全部消息
- 待我审批
- 审批结果
- 项目动态
- 系统公告

### 4.2 常用操作

1. 点击“消息中心”。
2. 按分类查看消息。
3. 点击消息查看详情。
4. 对未读消息进行阅读处理。

说明：

- 侧边栏消息中心会显示未读数量。
- 审批结果、待办提醒、公告等消息会汇总到这里。

## 5. 统一待办

统一待办用于汇总不同业务模块产生的审批和处理事项。

### 5.1 待办分类

页面包含以下页签：

- 待我处理
- 我发起的
- 我已处理
- 抄送我的

### 5.2 支持的业务类型

统一待办覆盖以下类型：

- 验工单
- 项目文件
- 产值分配
- 工时
- 投标
- 验收
- OA 申请

### 5.3 常用操作

1. 点击“统一待办”。
2. 选择页签，例如“待我处理”。
3. 使用业务类型筛选需要处理的事项。
4. 点击待办记录查看详情。
5. 按页面提示进行审批、查看、催办、撤回或抄送等操作。

说明：

- 如果某项业务还有单独审批页面，例如“验工审批”“项目文件审批”，也可以从对应页面处理。
- 统一待办适合日常集中处理所有审批事项。

## 6. 我的项目

“我的项目”展示当前登录用户参与的项目。

### 6.1 查看项目列表

1. 点击“我的项目”。
2. 可按状态筛选：
   - 全部
   - 进行中
   - 待验收
   - 已完成
   - 未开始
3. 可通过项目名称或项目编号搜索。

### 6.2 查看项目详情

1. 在项目卡片中点击“查看详情”。
2. 弹窗中可查看：
   - 项目基本信息
   - 合同信息
   - 合同主文件和附件
   - 项目阶段
   - 项目成员
   - 项目文件
   - 验工与审批相关记录

### 6.3 预览和下载文件

项目详情中支持预览和下载：

- 合同主文件
- 合同附件
- 项目文件
- 验收材料等附件

浏览器可直接预览的格式包括：

- PDF
- 图片：png、jpg、jpeg、gif、bmp、webp、svg
- 文本：txt、md、csv

不支持浏览器直接预览的格式，例如 doc、docx、xls、xlsx、ppt、pptx 等，系统会提示“暂不支持预览该格式，请点击下载后查看”。

### 6.4 上传项目文件

1. 在“我的项目”中打开项目详情。
2. 点击“上传文件”。
3. 填写文件名称。
4. 选择文件分类。
5. 选择所属项目阶段。
6. 上传文件。
7. 选择一级审批人。
8. 点击提交。

说明：

- 上传项目文件后会进入审批流程。
- 审批通过后文件归档到项目。
- 待审核状态下，上传人可撤销上传。

### 6.5 发起验工

1. 在“我的项目”中找到需要验工的项目。
2. 点击项目卡片中的“发起验工”。
3. 选择验工阶段。
4. 选择一级审批人。
5. 填写验工说明。
6. 上传验收材料。
7. 点击提交。

注意事项：

- 验工说明和验收材料为必填。
- 提交后进入验工审批流程。
- 审批未完成前，同一阶段可能受到重复提交限制。

## 7. 全部项目

“全部项目”通常用于管理员或项目管理人员维护全部项目。

### 7.1 查看全部项目

1. 点击“全部项目”。
2. 可按状态筛选：
   - 全部状态
   - 未开始
   - 进行中
   - 待验收
   - 已完成
3. 可通过项目名称或编号搜索。

### 7.2 新建项目

1. 点击“新建项目”。
2. 在“基本信息”中填写：
   - 项目名称
   - 项目编号
   - 项目类型
   - 预计开始时间
   - 预计结束时间
3. 在“合同信息”中填写：
   - 合同类型
   - 合同金额
   - 基本收费
   - 效益金额，如适用
   - 签订时间
   - 合同主文件
   - 合同附件
4. 在“成员分配”中选择：
   - 项目经理
   - 项目成员
5. 点击提交。

必填规则：

- 项目名称必填。
- 项目类型必选。
- 合同金额必须大于 0。
- 合同主文件必传。
- 至少选择一位项目经理。

### 7.3 编辑项目

1. 在全部项目列表中找到项目。
2. 点击编辑。
3. 修改项目基本信息、合同信息或成员信息。
4. 保存。

### 7.4 导入和导出项目

导出：

1. 点击“导出”。
2. 系统下载 Excel 文件。

导入：

1. 下载导入模板。
2. 按模板填写项目数据。
3. 上传模板文件。
4. 系统完成导入。

### 7.5 删除项目

1. 在全部项目列表中点击删除。
2. 系统弹出确认提示。
3. 确认后执行逻辑删除。

说明：

- 删除项目是不可逆操作，请谨慎操作。
- 删除逻辑会处理该项目下的业务数据，例如合同、项目文件、审批数据等。
- 固定配置数据，例如项目阶段模板，不会因为删除某个项目而删除。

项目生命周期用于查看项目从创建到归档的完整状态。

### 8.1 查看生命周期列表

1. 点击“项目生命周期”。
2. 搜索项目名称或编号。
3. 点击项目查看详情。

### 8.2 生命周期详情

详情页展示：

   - 已驳回

### 9.2 发起验工

## 10. 验工审批

验工审批用于审批别人提交给当前用户的验工单。

### 10.1 查看待审批验工单

1. 点击“验工审批”。
2. 查看页签：
   - 待审批
   - 已通过
   - 已驳回
   - 全部
3. 点击验工单查看详情。

### 10.2 审批通过

1. 打开待审批验工单。
2. 查看项目、阶段、验工说明、材料附件。
3. 填写审批意见。
4. 如果还需要继续流转，选择下一级审批人。
5. 如果当前为最终审批，勾选终审。
6. 点击“通过”。

注意事项：

- 审批意见必填。
- 非终审时必须选择下一级审批人。
- 终审通过后，验工单完成，项目阶段可进入后续产值分配条件。

### 10.3 驳回

1. 打开待审批验工单。
2. 填写审批意见或驳回原因。
3. 点击“驳回”。

被驳回后，发起人可根据业务需要重新发起或补充材料。

### 11.1 页面页签

页面包含：

## 15. 产值分配

产值分配用于根据项目阶段、合同金额和人员分配规则生成产值分配单。

### 15.1 创建前提

新建产值分配单前，需要满足：

- 项目阶段已经完成验工并通过。
- 当前阶段尚未被其他产值分配单确认。
- 项目合同金额、基本收费、效益金额等基础信息正确。
- 已确定参与分配的人员。

如果某一阶段已经被确认，则该阶段不能重复创建或确认产值分配单。

### 15.2 新建分配单

1. 点击“产值分配”。
2. 点击“新建分配单”。
3. 选择项目和阶段。
4. 系统自动展示本阶段应得产值。
5. 选择确认人。
6. 按人员填写分配比例或金额。
7. 检查公司账与员工实得的守恒预览。
8. 点击创建。

说明：

- 本阶段产值按“合同金额或调整后金额 × 当前阶段比例”计算。
- 如果合同为“基本 + 效益”模式，系统会基于基本收费和效益金额共同计算。
- 效益调整后，系统按调整后的合同价值重新计算当前阶段应得产值。

### 15.3 确认分配单

1. 确认人进入“产值分配”或“统一待办”。
2. 打开待确认的分配单。
3. 检查分配明细。
4. 点击确认。

注意事项：

- 如果同一项目阶段已经通过其他分配单确认，当前分配单不能再次确认。
- 系统会提示该阶段已通过其他分配单确定，无法二次确认。

### 15.4 审批分配单

1. 审批人打开待审核分配单。
2. 查看分配明细。
3. 审批通过或驳回。

### 15.5 发放分配单

1. 发放人打开已审批分配单。
2. 确认发放金额。
3. 点击发放。
4. 发放后会影响个人绩效统计。

### 15.6 导出产值分配

1. 点击“导出 Excel”。
2. 系统按当前查询条件导出分配单数据。

## 27. OA 系统使用说明

### 27.1 从 Edifice 进入 OA

1. 在 Edifice 工作台点击 OA 入口。
2. 系统生成 SSO 登录令牌。
3. 自动跳转到 OA。
4. 正常情况下无需再次输入账号密码。

如果跳转后要求重新登录：

- 检查当前 Edifice 登录状态是否有效。
- 检查 OA 地址和 SSO 配置是否正确。
- 检查两个系统的用户是否已同步。

### 27.2 从 OA 返回 Edifice

OA 顶部栏或工作台办公工具中可进入 Edifice。

操作方式：

1. 在 OA 页面找到 Edifice 入口。
2. 点击进入。
3. 系统通过反向 SSO 跳转回 Edifice。

### 27.3 OA 中维护用户

用户、员工、部门、岗位建议在 OA 维护。

常用位置：

- 人事管理
- 企业员工
- 部门架构
- 岗位职称
- 角色权限或权限组

常用操作：

1. 新增员工。
2. 批量导入员工。
3. 编辑员工基本信息。
4. 设置岗位。
5. 分配角色或权限组。
6. 修改密码。

### 27.4 OA 权限与 Edifice 菜单权限

Edifice 的菜单权限由 OA 中的权限配置控制。

常见配置流程：

1. 在 OA 中进入权限管理或角色权限。
2. 新增或编辑权限组。
3. 勾选需要开放的 Edifice 菜单，例如“工作台”“我的项目”“验工审批”等。
4. 将权限组分配给岗位或员工。
5. 保存后同步到 Edifice。
6. 用户重新登录 Edifice 后生效。

说明：

- 如果用户登录 Edifice 后侧边栏为空，通常是没有分配 Edifice 菜单权限。
- 修改权限后，在线用户可能会收到重新登录提示。

## 29. 常见业务流程

### 29.1 项目从创建到产值发放

1. 管理员在“全部项目”中新建项目。
2. 上传合同主文件和附件。
3. 设置项目经理和项目成员。
4. 项目成员在“我的项目”查看项目。
5. 项目经理按阶段发起验工。
6. 审批人在“验工审批”或“统一待办”中审批。
7. 验工终审通过后，该阶段具备产值分配条件。
8. 产值人员在“产值分配”中新建分配单。
9. 确认人确认分配单。
10. 审批人审批分配单。
11. 发放人执行发放。
12. 用户在“个人绩效”查看产值发放结果。
13. 财务在“回款记录”维护回款。
14. 项目完成后在“项目归档”归档并下载资料包。

### 29.2 项目文件审批流程

1. 用户在项目详情中上传项目文件。
2. 选择项目、阶段、分类和一级审批人。
3. 系统生成文件审批记录。
4. 审批人进入“项目文件审批”或“统一待办”处理。
5. 审批通过并终审后，文件归档到项目。
6. 审批驳回后，上传人可重新上传。

### 29.3 投标审批流程

1. 用户在“投标管理”新建投标。
2. 保存基础信息和附件。
3. 提交审批并选择一级审批人。
4. 审批人逐级审批。
5. 终审通过后投标审批完成。
6. 根据实际情况维护业务状态，例如中标、未中标、终止。

### 29.4 OA 用户同步流程

1. 管理员在 OA 中新增或导入员工。
2. OA 调用 Edifice 同步接口。
3. Edifice 创建或更新对应用户。
4. 用户可使用 OA 账号密码登录 Edifice。
5. 如果同步失败，后台定时任务进行补偿同步。

## 30. 常见问题

### 30.1 为什么看不到某个菜单？

原因通常是当前账号没有该菜单权限。

处理方式：

1. 联系管理员进入 OA。
2. 检查当前用户所属岗位、角色或权限组。
3. 勾选对应 Edifice 菜单权限。
4. 保存后重新登录 Edifice。

### 30.2 为什么从 Edifice 跳转 OA 还需要登录？

可能原因：

- 当前 Edifice 登录已过期。
- OA SSO 配置异常。
- OA 中没有对应员工。
- 两边用户同步失败。

处理方式：

1. 重新登录 Edifice 后再跳转。
2. 联系管理员检查 OA 员工数据。
3. 联系系统管理员检查 SSO 配置。

### 30.3 为什么项目阶段不能做产值分配？

可能原因：

- 该阶段验工未通过。
- 该阶段已经有产值分配单被确认。
- 项目合同信息不完整。
- 当前用户没有产值分配权限。

### 30.4 为什么审批时必须选择下一级审批人？

如果没有勾选终审，系统认为审批还要继续流转，因此必须选择下一级审批人。

如果当前就是最后一位审批人，请勾选终审后再通过。

### 30.5 为什么 Excel 文件不能预览？

浏览器通常不能原生预览 xls、xlsx 文件。请点击下载后使用本地 Excel 或 WPS 打开。

### 30.6 为什么个人绩效没有数据？

可能原因：

- 当前用户没有参与项目。
- 当前用户未被分配到产值单。
- 产值单未发放。
- 当前账号不是对应员工账号。

### 30.7 为什么权限修改后还显示旧菜单？

可能是浏览器仍保留旧登录态。请退出 Edifice 后重新登录。

- 项目文件尽量按阶段归档。
- 验工材料应上传可证明阶段完成情况的文件。

## 33. 使用边界与注意事项

- Edifice 菜单权限由 OA 控制，不在 Edifice 单独配置。
- 修改权限后，用户应重新登录。
- 项目文件和合同附件可下载，但不是所有格式都支持浏览器预览。

- 项目删除为逻辑删除，但仍会影响该项目下业务数据，请谨慎操作。
- 操作审计、流程配置、业务规则配置属于管理员功能，普通用户不建议开放。
